# Data

This project uses four NumPy arrays from the original internship exercise:

- `x_train.npy`
- `y_train.npy`
- `x_test.npy`
- `y_test.npy`

The dataset contains smartphone sensor features collected for human activity recognition.

The provided data includes:

- 7,352 training samples
- 2,947 test samples
- 561 features
- 6 activity classes

The six activity labels represent:

1. Walking
2. Walking upstairs
3. Walking downstairs
4. Sitting
5. Standing
6. Lying

## File Structure

To run the project, place the four `.npy` files in the `data/` folder:

    data/
    ├── x_train.npy
    ├── y_train.npy
    ├── x_test.npy
    └── y_test.npy

The raw data files are not included in this repository.
